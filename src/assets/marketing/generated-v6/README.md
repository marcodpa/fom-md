# Fotografías de la propuesta v6

27 imágenes independientes generadas con la herramienta integrada `image_gen`, usando las láminas de `output/rediseno-completo-v6` como referencia visual. Son imágenes sintéticas fotorrealistas, no fotografías documentales de clientes o instalaciones reales.

`prompts.json` registra las instrucciones y referencias de generación. Los PNG originales se conservan. Las secciones se asignan por nombre en `src/content/v6-photography.js`; reemplazar una foto no modifica el texto ni la estructura de la página.

Las pantallas destacadas usan capturas de `src/assets/marketing/real`, montadas con `ScenePhoto.jsx`. Ninguna lámina completa de la propuesta se importa o recorta para construir el sitio.
